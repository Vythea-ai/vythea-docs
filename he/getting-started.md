Vythea הוא סוכן AI שנשאר פתוח לצד העבודה שלכם: חלון, וגם אותו סוכן בטרמינל. הוא קורא קבצים וכותב אליהם, מריץ פקודות (אחרי שישאל אתכם קודם), שומר הערות עליכם בדיסק שלכם, ומדבר עם המודלים שתבחרו.

## 1. יצירת חשבון

[הירשמו](https://vythea.com/signup) ב-vythea.com. כל עוד Vythea בגרסת אלפא, ההורדות כרוכות בחשבון. החשבון מחזיק גם את הקרדיט שלכם למודלים שמאוחסנים אצלנו, את התוכנית שלכם ואת הצוותים שלכם.

## 2. התקנה

פתחו את עמוד [הורדה](https://vythea.com/dashboard/download) בלוח הבקרה. הדף מציע קודם את המערכת שלכם:

- **macOS** (13 ומעלה, Apple silicon): העתיקו את הפקודה בת השורה האחת והדביקו אותה בטרמינל. היא מתקינה את החלון ואת הטרמינל ופותחת את Vythea, בלי אזהרה לאשר. אפשר גם לפתוח את קובץ ה-.dmg ולגרור את Vythea לתיקיית Applications; בפעם הראשונה macOS עשוי לומר שאינו יכול לאמת את Vythea: סגרו את ההודעה, פתחו את הגדרות המערכת › פרטיות ואבטחה, לחצו על **פתח בכל זאת** ליד Vythea ואשרו. צריך לעשות זאת רק פעם אחת.
- **Windows** (11, x64): הורידו את קובץ ה-.zip, חלצו אותו והריצו את `vythea.exe setup` – או העתיקו את הפקודה בשורה אחת והדביקו אותה ב-PowerShell, והיא עושה את שניהם.
- **Linux** (x64, glibc 2.31 ומעלה): הורידו את קובץ ה-.tar.gz, חלצו אותו והריצו את `./vythea setup` – או הדביקו את הפקודה בשורה אחת בטרמינל.

אין צורך בהרשאות מנהל, ושום דבר לא נשמר מחוץ לחשבון המשתמש שלכם במחשב, מלבד האפליקציה בתיקיית Applications ב-Mac.

## 3. הגדרה

`vythea setup` שואל איך לקרוא לכם, מחבר אתכם לחשבון, בוחר שער ומודל, ומציב את החלון, את הטרמינל או את שניהם במקום שתבחרו. הריצו אותו שוב בכל עת כדי לשנות את התשובות. ב-Windows וב-Linux האפליקציה מופיעה אחר כך בתפריט התחל או בתפריט היישומים.

## 4. התחברות

ההתחברות מתבצעת ב-vythea.com: האפליקציה פותחת את האתר בשבילכם, או הריצו `/login` בטרמינל. אחר כך המחשב מופיע תחת [מכשירים](https://vythea.com/dashboard/devices).

## 5. שאלו אותו משהו

הקלידו הודעה. Vythea עונה עם המודל שבחרתם, ושואל לפני שהוא מריץ פקודה או משנה קובץ. המודלים שמאוחסנים אצלנו משולמים מהקרדיט שלכם; כדי להשתמש במפתחות ה-API שלכם במקום זאת, ראו [שערים](gateways.md).
